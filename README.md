# Brightloop — Subscription Management System
## Odoo Hackathon 2026 | Shared engineering baseline

Brightloop helps a software business manage products, subscription plans, quotations, renewals, invoices, payments, discounts, and subscription reporting in one place.

> **Repository status:** This repository is being standardized for implementation. Documentation describes the agreed target design; it does not mean every application component has already been implemented or tested.

| Layer | Standard |

Verify this requirement before relying on the standalone architecture for final submission.

## Architecture

Browser UI → FastAPI → Supabase PostgreSQL. The browser must not contain a Supabase service-role key. FastAPI owns business workflows, authorization, pricing, taxes, discount application, subscription lifecycle, invoice generation, and payment validation. A backend scheduled worker handles recurring billing. The AI assistant can only call approved backend tools and must not execute arbitrary SQL.

## Core user journey

1. Admin configures products, variants, plans, taxes, and discounts.
2. A customer receives or accepts a quotation and confirms a subscription.
3. The subscription becomes active according to the agreed lifecycle rules.
4. A scheduled backend job identifies billing due and creates at most one invoice per subscription and billing period.
5. Staff confirm/send invoices and record payments.
6. The dashboard reflects active subscriptions, revenue, paid and outstanding amounts, and overdue invoices.
7. Customers can access only their own subscriptions and invoices.
